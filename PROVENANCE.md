# Source and authorship

This standalone submission starts from the public [Atomity forecasting challenge](https://github.com/atomityhq/forecasting-challenge) at commit `6e5ac0e`. The original assignment documents, dataset contracts, license, starter utilities and starter tests are retained. The initial import commit records that source snapshot; it does not claim authorship of the upstream material.

The forecasting pipeline, analysis, additional tests, generated predictions and report are additions for this submission. AI assistance was used for implementation, analysis and drafting, as disclosed in the README and final report. Commit authorship identifies the submitting account; it is not a claim of entirely unaided work.

The fixed `data-v1` release derives from Microsoft Azure Public Dataset V2. The input release is downloaded and checksum-verified rather than committed here. See SOURCES.md, DATASET.md and the downloaded DATA_CARD.md for provenance and sampling limitations.
